# College Student Data Analysis Project

## 📌 项目简介
这是一个基于 Python 的数据分析项目，旨在探究当代大学生在 AI 工具使用偏好、娱乐方式及时间分配上的群体差异。

## 🛠️ 技术栈
*   **语言**：Python
*   **数据处理**：Pandas (数据清洗、分组统计)
*   **数据可视化**：Matplotlib (柱状图、折线图生成)
*   **辅助工具**：AI 辅助代码生成与 Debug

## 📂 数据文件说明
*   `01_AI平台活跃渗透率.csv`：各大模型在大学生群体中的使用率。
*   `02_AI用户年龄与城市分布.csv`：用户画像基础数据。
*   **代码文件**：`数据分析脚本.py`。

## 📈 核心发现
- **平台分化**：短视频/社交渗透见顶，AI 原生 App 成为唯一高速增长引擎，分流了年轻人的碎片时间。
- **线下趋势**：消费向“强社交、重体验”倾斜（如餐饮聚会、剧本杀），传统纯观看型（如影院）相对弱势。
- **时间与情绪**：娱乐呈现“高频、碎片化”（1-3小时为主），且伴随“玩多了会焦虑”的普遍拉扯感。
- **用户画像**：AI 用户以 18-30 岁为主，且二线及以下城市占比突出，下沉市场是未来的增长重点。
- **总体洞察**：年轻人娱乐正从“刷内容”转向“用工具、重体验”，理解他们需抓住“娱乐焦虑”与“下沉市场”两个关键词。
